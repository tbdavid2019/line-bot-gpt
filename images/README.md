# Images 資料夾

這個資料夾用於存放 Gemini AI 生成的圖片。

## 檔案命名規則

生成的圖片會使用以下命名格式：
```
YYYY-MM-DDTHH-MM-SS-sssZ_[清理過的提示詞].[副檔名]
```

例如：
- `2024-09-04T12-30-45-123Z_一隻可愛的小貓咪.jpg`
- `2024-09-04T12-31-20-456Z_beautiful_sunset_ocean.png`

## 注意事項

- 圖片會自動保存到這個資料夾
- 檔案名稱中的特殊字符會被替換為底線
- 請定期清理舊檔案以節省空間
- 這個資料夾已在 .gitignore 中設定為不追蹤圖片檔案
